# Arkpedia Chibis Dev 0.8.2

## Desktop windows load again

Fixed the empty window on macOS and Windows. The model library no longer intercepts the JavaScript and CSS needed to start the app.

## Clear offline downloads

Catalogue checkboxes now explain that they select models for offline download. **Download models (2)** opens a dedicated download dialog with the selected count, download progress, errors and model-library actions. Closing it returns to the catalogue with your selection intact. The **+** buttons still add companions directly to your desktop.

App settings and updates remain in Settings.

Builds remain unsigned development previews.
